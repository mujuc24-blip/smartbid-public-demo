# SmartBid 공개 체험판

공개 조달표본 기반 정적 UI입니다. 고정 표본이며 자동 갱신되지 않습니다. 전체 업체·수주 현황이나 계약 연결 확정을 의미하지 않습니다.

업체를 열어 계약과 행 이력을 확인할 수 있습니다. 우호도 기본값은 미평가, 구매상태 기본값은 미확인입니다. 메모와 상태는 이용자 기기의 브라우저 localStorage에만 저장되고 서버 업로드·기기 간 공유되지 않습니다. 개인정보·비밀키·민감정보를 입력하지 마세요. 브라우저 저장소를 지우면 입력이 삭제됩니다.

이 저장소의 정적 코드와 공개 표본은 모두 공개됩니다.
